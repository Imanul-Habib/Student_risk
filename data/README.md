# Dataset

Place the supplied dcs_student_data.csv in this directory.

The training code expects it at data/dcs_student_data.csv.

The supplied dataset contains 10,030 rows and 21 columns. Preprocessing removes 30 exact duplicate rows, leaving 10,000 rows before policy labels are filtered for missing Attendance or Final_Score.

The full CSV should only be committed when repository data-sharing is appropriate.
